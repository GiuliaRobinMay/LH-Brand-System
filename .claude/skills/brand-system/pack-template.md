# CLIENT — brand pack

**Status: in progress.** 🔒 = settled. ⏳ = open, must not be treated as decided.
Never invent a value for an open section — ask.

## 1. The World
Villain · What's at stake · Main character · Guide · Practice · Promise
Quote real evidence. Harvest language, don't invent it.

## 2. Voice
Native phrases (verbatim, sourced) · How the audience actually writes · Never-do list

## 3. Vocabulary
The brand's proper nouns: roles, stages, rituals, products, member-given names

## 4. Imagery & character rules
What form of imagery is allowed where, and what is forbidden. Model sheet if there
is a character. Generation prompts if AI imagery is used.

## 5. Colour
One value per role, with the job it does and its contrast pair. Record where each
value was extracted from. Note any drift found and how it was reconciled.

## 6. Typography
Families, licences, scale, weights, fallback stacks with close metrics.

## 7. Accessibility floor
Minimum type size, contrast ratio, hit target — set by the audience, not by taste.

## 8. Anti-patterns
What this brand must never do, and why.

## 9. Mandate
How far the work reaches: systematise / modernise / rebuild. What is untouchable.
